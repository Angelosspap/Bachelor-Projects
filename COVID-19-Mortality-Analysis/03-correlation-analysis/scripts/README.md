# R Scripts

This folder contains the R script used to reproduce the COVID-19 cases-versus-deaths correlation analysis.

## Main script

`COVID19_Correlation_Analysis.R`

The script:
- Loads the monthly COVID-19 dataset.
- Calculates Spearman correlation coefficients for five countries.
- Reproduces five country-specific scatter plots (Figures 4.21–4.25 of the original report).

Run the script from the `03-correlation-analysis` directory.
