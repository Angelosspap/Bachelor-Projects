# Correlation Analysis Figures

This folder contains five country-specific scatter plots showing the relationship between monthly COVID-19 cases and deaths.

The figures reproduce the analyses presented in Section 4.4 (Figures 4.21–4.25) of the original university report.

## Figures

- `greece_cases_vs_deaths.png` — Greece
- `italy_cases_vs_deaths.png` — Italy
- `denmark_cases_vs_deaths.png` — Denmark
- `belgium_cases_vs_deaths.png` — Belgium
- `finland_cases_vs_deaths.png` — Finland

Each scatter plot displays monthly COVID-19 cases on the horizontal axis and monthly deaths on the vertical axis.
